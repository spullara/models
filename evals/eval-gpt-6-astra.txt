    Every third move must be diagonal when a diagonal move is possible.
    Time: O(N^2). Space: O(N^2).

    # when the number of moves already taken is phase modulo 3.

            if diagonal_possible:
                moves.append((r + 1, c + 1, "X"))

                if phase == 2 and diagonal_possible:
                    allowed = [(r + 1, c + 1, "X")]
                else:
                    allowed = moves
