### Method Explanation

We model the problem as finding the maximum-weight path in a Directed Acyclic Graph (DAG):
1. **State Representation**: Each state is defined by `(r, c, m)`, where:
   - `(r, c)` is the current cell coordinates.
   - `m` is the number of moves made so far modulo 3 (`m ∈ {0, 1, 2}`).
2. **Move Restrictions**:
   - The next move is the $(k+1)$-th move. It is a required diagonal move if and only if `m == 2` (since $(k+1) \equiv 0 \pmod 3$).
   - When `m == 2`:
     - If moving diagonally (`X`) is possible (`r + 1 < N` and `c + 1 < N`), we **must** move diagonally.
     - Otherwise, we may move right (`R`) or down (`D`) if within grid boundaries.
   - When `m != 2`:
     - All moves within grid boundaries (`R`, `D`, `X`) are valid.
3. **DP Computation**:
   - Every move strictly increases $r + c$. Thus, we can iterate backwards by the sum of coordinates $s = r + c$ from $2(N - 1)$ down to $0$.
   - We record the best move at each state to reconstruct the optimal path string in $O(N^2)$ time and space.

def solve_grid(grid: list[list[int]]) -> tuple[int, str]:
    n = len(grid)
    if n == 0:
        return 0, ""
    if n == 1:
        return grid[0][0], ""

    # dp[r][c][m] will store the maximum sum from (r, c) to (n-1, n-1)
    # when m moves have been made so far (mod 3).
    dp = [[[-float("inf")] * 3 for _ in range(n)] for _ in range(n)]
    best_move = [[[None] * 3 for _ in range(n)] for _ in range(n)]

    # Base cases at the destination (n-1, n-1)
    for m in range(3):
        dp[n - 1][n - 1][m] = grid[n - 1][n - 1]

    # Process states in reverse topological order (by decreasing r + c)
    for s in range(2 * n - 3, -1, -1):
        for r in range(max(0, s - (n - 1)), min(n, s + 1)):
            c = s - r
            can_r = c + 1 < n
            can_d = r + 1 < n
            can_x = can_r and can_d

            for m in range(3):
                # Determine available moves according to the rules
                if m == 2:
                    # Every 3rd move MUST be diagonal if possible
                    if can_x:
                        candidates = [("X", r + 1, c + 1)]
                    else:
                        candidates = []
                        if can_r:
                            candidates.append(("R", r, c + 1))
                        if can_d:
                            candidates.append(("D", r + 1, c))
                else:
                    candidates = []
                    if can_r:
                        candidates.append(("R", r, c + 1))
                    if can_d:
                        candidates.append(("D", r + 1, c))
                    if can_x:
                        candidates.append(("X", r + 1, c + 1))

                next_m = (m + 1) % 3
                best_val = -float("inf")
                chosen_move = None

                for move_char, nr, nc in candidates:
                    val = grid[r][c] + dp[nr][nc][next_m]
                    if val > best_val:
                        best_val = val
                        chosen_move = move_char

                dp[r][c][m] = best_val
                best_move[r][c][m] = chosen_move

    # Reconstruct the optimal path starting from (0, 0) with 0 moves made
    path = []
    curr_r, curr_c, curr_m = 0, 0, 0
    while (curr_r, curr_c) != (n - 1, n - 1):
        move = best_move[curr_r][curr_c][curr_m]
        path.append(move)
        if move == "R":
            curr_c += 1
        elif move == "D":
            curr_r += 1
        elif move == "X":
            curr_r += 1
            curr_c += 1
        curr_m = (curr_m + 1) % 3

    return dp[0][0][0], "".join(path)
